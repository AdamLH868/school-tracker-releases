# School Tracker downloads

Installers for [School Tracker](https://canvas-track-core.base44.app/download), a private dashboard for your Canvas courses, deadlines and grades. The source code lives in a private repository; this repo only hosts releases.

- **Windows app:** [School-Tracker-Setup.exe](https://github.com/AdamLH868/school-tracker-releases/releases/latest/download/School-Tracker-Setup.exe). Not code-signed yet: if Windows says "Windows protected your PC", click **More info** → **Run anyway**. It updates itself.
- **Chrome extension:** coming to the Chrome Web Store. Until then, [download the zip](https://github.com/AdamLH868/school-tracker-releases/releases/latest/download/school-tracker-extension-unpacked.zip), unzip it, open `chrome://extensions`, turn on Developer mode and click **Load unpacked**.

Setup guide and privacy policy: https://canvas-track-core.base44.app/download · https://canvas-track-core.base44.app/privacy
